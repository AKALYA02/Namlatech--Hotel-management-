# JUST STAY - Hotel List System

## Project Description

The Hotel Management System is a web-based application developed using React JS. This application helps users to view and manage hotel information easily. Users can explore hotel details, view hotel images, check prices, and find hotel locations through an interactive map.

## Technologies Used

- React JS
- JavaScript
- HTML
- CSS
- React Router DOM
- Redux Toolkit
- React Leaflet
- Vite

## Features
  
  Users can view the list of available hotels.
- Users can view hotel names, descriptions, images, and prices.
- Users can add new hotel details.
- Users can edit existing hotel information.
- Users can delete hotel records.
- The application provides mandatory field validation.
- Users can view hotel locations on an interactive map using latitude and longitude.
- The application provides a simple and user-friendly interface.

## Hotel Details

Each hotel record contains the hotel name, description, latitude, longitude, price, and image.

## Installation and Setup

Step 1: Clone the GitHub repository.

```bash
git clone https://github.com/AKALYA02/Namlatech--Hotel-management-.git
```

Step 2: Navigate to the project folder.

```bash
cd Namlatech--Hotel-management-
```

Step 3: Install the required dependencies.

```bash
npm install
```

Step 4: Start the development server.

```bash
npm run dev
```

Step 5: Open the localhost URL in your browser to access the application.
